# Babanoell Loans 1.0.1

هسته مستقل تسهیلات فاز ۲ پلتفرم بابانوئل.

- PHP خالص، API v1، دیتابیس مستقل.
- طرح‌های بازاری/لیزینگی با نسخه‌بندی immutable و pin شدن نسخه در پرونده.
- پورت دقیق دو موتور محاسبات Legacy همراه Golden Fixture.
- پرونده، گردش‌کار مرکزی، Audit، زمان‌بندی اقساط و ضامن‌ها.
- احراز هویت فقط از طریق Identity Bearer؛ بدون دسترسی مستقیم به DB احراز هویت.
- Installer و Updater وب برای cPanel.
- UI فارسی RTL مشترک با Identity/Panel.
