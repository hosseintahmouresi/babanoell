# Loans 1.0.2 — پایداری گردش‌کار، داده و رابط

- اصلاح ماشین وضعیت، جلوگیری از انتقال به همان وضعیت و اتمیک‌شدن تغییر مسئول بانک همراه با تغییر وضعیت.
- الزام دلیل برای «نقص مدارک»، «رد» و «لغو» و ثبت تلاش‌های نامعتبر در Audit.
- تثبیت Version Pinning پرونده؛ نوع و تنظیمات پرونده از نسخه پین‌شده طرح خوانده می‌شوند، نه نسخه جاری طرح.
- جلوگیری از تغییر نوع طرح بازاری/لیزینگی بعد از ایجاد طرح.
- انتقال کنترل دسترسی فهرست پرونده‌ها به Query پیش از صفحه‌بندی و افزودن ایندکس‌های لازم با migration جدید.
- سازگاری وضعیت migration با نصب‌های قبلی: رکوردهای معتبر قدیمی بدون اجرای دوباره شناسایی می‌شوند و tracking مستقل `loans_schema_migrations` حفظ می‌شود.
- اعتبارسنجی و Audit کامل‌تر ضامن‌ها و ویرایش پیش‌نویس.
- پشتیبانی از ارقام فارسی/عربی در مبلغ، تعداد اقساط، فاصله اقساط، درصدها و تنظیمات عددی API.
- بازنویسی پیام‌های اعتبارسنجی طرح به فارسی قابل‌فهم و حذف نام کلیدهای فنی از پیام کاربر.
- یکپارچه‌سازی کامل **Babanoell UI 1.3.0**، کنتراست اصلاح‌شده و تاریخ/ساعت شمسی تهران در تمام نماهای کاربری.
