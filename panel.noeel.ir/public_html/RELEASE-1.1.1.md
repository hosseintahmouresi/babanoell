# Panel 1.1.1 — تکمیل تجربه کاربری تسهیلات و یکپارچگی UI

- همگام‌سازی کامل با **Babanoell UI 1.3.0** و همان Core بصری Identity/Loans.
- تثبیت متغیرهای طراحی، کنتراست متن‌ها، مرزها، شعاع‌ها و تمام modifierهای مورد استفاده در ماژول تسهیلات.
- فرم پویا برای طرح بازاری/لیزینگی و جلوگیری از ارسال فیلدهای نامرتبط.
- صفحه‌بندی طرح‌ها و پرونده‌ها، پیام نتیجه عملیات و نمایش معنایی مبلغ، درصد، تعداد و وضعیت.
- تکمیل ویرایش پیش‌نویس، ضامن‌ها، تاریخچه وضعیت و رویدادهای پرونده.
- نمایش تاریخ‌ها و ساعت‌ها به‌صورت شمسی و بر مبنای Asia/Tehran؛ سررسید اقساط به‌صورت تاریخ شمسی بدون ساعت.
- پذیرش ورودی‌های عددی فارسی در محاسبه‌گر و فرم‌های مالی از طریق normalization سمت پنل/سرویس.
- هیچ کلاس `bn-*` استفاده‌شده در صفحات عملیاتی بدون تعریف CSS باقی نمانده و CSS/JS همچنان کاملاً جدا از PHP هستند.
