# Panel 1.2.0 — Phase 3 Documents

- Adds the Documents module with private upload, review, version history and secure short-lived download links.
- Loan request pages expose the required-document checklist and direct entry to document management.
- Plan forms define required documents per immutable plan version.
- Dashboard, sidebar and system health now include Documents.
- Existing installations remain compatible through the default `https://documents.noeel.ir` endpoint.
- UI remains Babanoell UI 1.3.0.
