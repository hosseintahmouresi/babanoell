# Panel 2.13.0 — پایش امن و یکپارچه سرویس‌ها

- صفحه فقط‌خواندنی `/system/health` با دسترسی صرفاً `super_admin`.
- بررسی GET مسیرهای سلامت شش سرویس مستقل و وضعیت تنظیمات Panel، همراه HTTP و زمان پاسخ.
- محدودیت دوثانیه‌ای هر درخواست؛ جلوگیری از تبدیل صفحه سلامت به SSRF از طریق آدرس‌های اختیاری.
- نمایش تفکیک‌شده پاسخ سالم، HTTP موفق اما وضعیت نامشخص، اختلال و عدم دسترسی؛ هیچ عدد جعلی نمایش داده نمی‌شود.
- عدم نمایش بدنه پاسخ، خطاهای فنی محرمانه، کلیدها یا اطلاعات کاربران.
- اصلاح متادیتای ServiceBoundary برای Integrations فعال.
- بدون تغییر دیتابیس، مالی، قرارداد، هویت یا API سرویس‌های دیگر.

این انتشار برابر با تکمیل همه قابلیت‌های افزونه مرجع نیست؛ فاز ۱۰ را به‌صورت مرحله‌ای پیش می‌برد.
