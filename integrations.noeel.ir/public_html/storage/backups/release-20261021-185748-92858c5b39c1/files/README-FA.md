# راهنمای بازیابی دستی ورود Integrations (نسخه 1.1.0 → 1.1.1)

این بسته فقط برای زمانی است که **به علت مشکل ورود به مرکز به‌روزرسانی** نمی‌توان ZIP نسخه 1.1.1 را از طریق صفحه Update نصب کرد. این بسته **نسخه کامل 1.1.1 نیست**؛ فقط کد گزارش‌دهی خطای ورود را به‌طور موقت نصب می‌کند تا امکان اعمال آپدیت اصلی فراهم شود.

## مراحل دقیق

1. از پوشه سرویس `integrations.noeel.ir/public_html` یا ریشه واقعی کد Integrations بکاپ کامل بگیرید. اگر مسیر روی هاست متفاوت است، پوشه‌ای را پیدا کنید که `bootstrap.php`، `config/` و `public/` را دارد.
2. فایل‌های زیر را از ZIP استخراج کنید و با حفظ مسیر نسبی در **ریشه کد سرویس** جایگزین فایل‌های قبلی کنید:
   - `public/update.php`
   - `src/Http/IdentityAdminClient.php`
3. **فایل‌های `config/local.env.php`، پوشه `storage/`، دیتابیس، فایل install و سایر سرویس‌ها را تغییر ندهید.**
4. نسخه Identity 1.12.1 به‌تنهایی مجوز ورود Production را فعال نمی‌کند. در `identity.noeel.ir/config/local.env.php` باید تنظیمات فعال‌سازی امن ورود مطابق راهنمای بسته Identity اعمال شده باشد؛ ترجیحاً تیم فنی در محیط امن انجام دهد. مقادیر ضروری عبارت‌اند از `APP_ENV=production` و `AUTH_ENVIRONMENT=production`، `AUTH_ALLOW_HTTP_LOGIN_IN_PRODUCTION=true`، `AUTH_LOGIN_ENABLED=true`، `AUTH_SESSION_ISSUING_ENABLED=true`، `AUTH_REQUIRE_TOKEN_PEPPER=true` و `AUTH_TOKEN_PEPPER` با مقدار امن تصادفی حداقل ۳۲ کاراکتر. **اگر AUTH_TOKEN_PEPPER از قبل مقدار امنی دارد آن را عوض نکنید.** کلیدها را در پیام ارسال نکنید.
5. سپس `https://integrations.noeel.ir/update.php` را باز کنید. اگر صفحه ورود نشان داده می‌شود، در صورت بروز خطا باید متن مشخصی مانند `Identity HTTP 501`، مشکل امضا یا خطای ارتباط نمایش داده شود، نه پیام مبهم نسخه قبلی.
6. پس از برطرف‌کردن علت ورود، از همان آپدیتر، **بسته کامل `Noel_Integrations_1.1.1_Login_Diagnostics.zip`** را نصب کنید تا نسخه، مانیفست و همه فایل‌ها هماهنگ شوند.

## نکته تشخیصی

اگر آدرس آپدیتر به‌جای فرم ورود، خطای HTTP 500، 403 یا صفحه سفید نشان داد، خطای سرور باید از `error_log` وب‌سرور/PHP خوانده شود؛ فایل‌های این بسته به‌تنهایی تضمین رفع این دسته از خطاها را نمی‌دهند. هنگام ارسال گزارش، رمز و کلیدها و توکن‌ها را حذف کنید.

پس از این جایگزینی، در صورت وجود دسترسی نوشتن به `storage/`، فایل `storage/identity-login-diagnostics.log` فقط فراداده فنی (کد خطا و وضعیت HTTP) ثبت می‌کند و حاوی رمز یا توکن نیست. این فایل را عمومی نکنید.

## بازگشت

اگر پس از اعمال این اصلاح صفحه باز نشد، همان دو فایل بکاپ‌گرفته‌شده را برگردانید. این بسته به دیتابیس دست نمی‌زند.
