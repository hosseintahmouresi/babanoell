# رفع خطای HTTP 500 در نصب Integrations نوئل

**بسته رفع اشکال نصب اولیه سرویس Integrations 1.0.0؛ بدون تغییر API یا دیتابیس.**

## اعمال رفع اشکال روی سرویس نصب‌نشده

1. از فایل `public/install.php` روی هاست یک بکاپ بگیرید.
2. فایل اصلاح‌شده `public/install.php` این بسته را دقیقاً جایگزین فایل فعلی در مسیر `public/install.php` ساب‌دامین Integrations کنید. **کل سرویس را دوباره نصب/پاک نکنید**.
3. به `https://integrations.noeel.ir/install.php` مراجعه کنید. چک‌های پیش‌نیاز اکنون پیام مشخص ارائه می‌کنند و به‌جای پرتاب استثنای بدون مدیریت، HTTP 503 همراه راهنمای رفع می‌دهند.
4. اگر پیام `NOEEL_SERVICE_SHARED_SECRET` نمایش داده شد، **همان کلید مشترک قبلی سرویس‌های نوئل** را در `config/local.env.php` قرار دهید. مقدار جدید مستقل تولید نکنید، زیرا احراز هویت بین سرویس‌ها خراب می‌شود.
5. کلید `INTEGRATIONS_INSTALL_KEY` باید مستقل، تصادفی و حداقل ۳۲ کاراکتری باشد. توصیه: `php -r 'echo bin2hex(random_bytes(32)), PHP_EOL;'`.
6. اگر خطای نحوی در `config/local.env.php` اعلام شد: `php -l config/local.env.php`. کل فایل باید ساختار PHP `return [ ... ];` داشته باشد.
7. اگر خطای Extension یا سطح دسترسی داشتید، آن را برای PHP مربوط به همین ساب‌دامین برطرف کنید؛ پوشه `storage` و `storage/tmp` باید توسط PHP قابل نوشتن باشند.

## محدوده تغییر

- عدم استفاده از `Config::requireSecret()` در مرحله preflight نصب (در نبود کلید قبلاً HTTP 500 ایجاد می‌کرد)
- بررسی ایمن و پیام‌های قابل‌فهم برای فایل تنظیمات، کلید مشترک، PHP extensionها و دسترسی storage/session
- مدیریت خطای نحوی فایل `local.env.php` بدون نمایش اطلاعات حساس
- بدون تغییر رمزها، اسکیما، APIها، قرارداد OTP، یا سایر سرویس‌ها

اگر بعد از جایگزینی **باز هم HTTP 500** مشاهده شد، باید خطوط همان لحظه در PHP `error_log`/`php-fpm` هاست بررسی شود؛ امکان تشخیص قطعی خطای سمت سرور از تصویر مرورگر وجود ندارد. اطلاعات محرمانه را ارسال نکنید.

## نتایج تست آفلاین

- سناریوهای preflight: ۵/۵ موفق (نبود فایل تنظیمات، کلید نصب، کلید مشترک، extension، و خطای syntax)
- تست‌های داخلی Integrations: ۸/۸ موفق
- PHP syntax: بدون خطا
- اتصال واقعی MySQL، پیامک و ارائه‌دهندگان شبکه در این محیط تست نشده است.
