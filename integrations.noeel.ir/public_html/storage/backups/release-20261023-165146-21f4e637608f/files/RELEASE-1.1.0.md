# نوئل — یکپارچه‌سازی Integrations 1.1.0

این نسخه با سورس واقعی **Partners/Panel** تطبیق داده شده است تا ظاهر و تجربه کاربری مرکز به‌روزرسانی یکسان باشد.

## نصب روی نسخه 1.0.0 که در حال حاضر روی هاست نصب است

1. **از فایل‌ها و دیتابیس Integrations بکاپ بگیرید**؛ تنظیمات موجود را پاک نکنید.
2. `https://integrations.noeel.ir/update.php` را باز کنید. صفحه قدیمی هنوز کلید `INTEGRATIONS_INSTALL_KEY` را می‌خواهد؛ این **آخرین بار** است.
3. فایل `Noel_Integrations_1.1.0_UNIFIED_UPDATE.zip` را آپلود کنید و به‌روزرسانی را اجرا کنید.
4. پس از اعمال، `update.php` جدید را باز کنید. فرم ورود با حساب **super_admin سرویس Identity** و رابط مشترک نوئل نمایش داده می‌شود.
5. آدرس `/` در مرورگر به مرکز مدیریت نسخه هدایت می‌شود؛ مسیرهای `/health`, `/healthz` و API v1 همچنان دست‌نخورده‌اند.

**هیچ نیازی به ساخت دیتابیس جدید، پاک‌کردن تنظیمات یا نصب مجدد Partners نیست.** فایل خصوصی `config/local.env.php` و وضعیت نصب `storage/installed.lock` هرگز در این بسته نیستند.

اگر URL سرویس Identity غیرمعمول است، تنظیم `INTEGRATIONS_IDENTITY_BASE_URL` را در `config/local.env.php` اضافه کنید؛ مقدار پیش‌فرض `https://identity.noeel.ir` است.

در محیط عملیاتی پشت reverse proxy، اگر HTTPS تشخیص داده نمی‌شود، آدرس‌های IP پروکسی مورد اعتماد را با `NOEEL_TRUSTED_PROXIES` و مطابق تنظیم سرویس‌های قبلی مشخص کنید؛ **نباید X-Forwarded-Proto را بدون بررسی IP پروکسی قابل اعتماد بپذیرید.**

## قابلیت‌های هماهنگ‌شده

- لوگو، پالت رنگ، تایپوگرافی، فرم‌ها، هدر/فوتر، RTL و Responsive بر اساس CSS/JS سرویس Partners.
- ورود مدیر ارشد **Identity** با همان API مرکزی؛ حذف کلید نصب از فرایند آپدیت‌های بعدی.
- اعتبارسنجی مرحله‌ای بسته، CSRF، محدودسازی تلاش ورود، تأیید هش فایل‌ها، جلوگیری از نسخه پایین‌تر و بسته‌های نامعتبر.
- نگهداری بکاپ فایل‌ها، ثبت وضعیت انتشار و مسیر بازیابی؛ Migrationهای موجود همچنان حفظ شده‌اند.
- وضعیت اتصال دیتابیس و وضعیت پیکربندی ارائه‌دهندگان بدون نمایش کلیدها.

**توجه:** اولین نصب این به‌روزرسانی با آپدیتر قدیمی سرویس انجام می‌شود که قابلیت بازیابی خودکار ندارد. از آپدیت بعدی، سازوکار بازیابی یکپارچه فعال خواهد بود. تغییرات این بسته به دیتابیس نیاز ندارند.

## مرزهای تست

تست‌های آفلاین با PHP CLI و بازرسی ساختار ZIP اجرا شده‌اند. تست زنده احراز هویت Identity، نصب واقعی هاست، MySQL و ارائه‌دهندگان در این محیط انجام نشده‌اند؛ این موارد در فرایند QA تیم فنی پوشش داده می‌شوند.
