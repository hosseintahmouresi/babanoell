# بستهٔ ارتقای بابانوئل ۲.۱۷

این کیت برای **به‌روزرسانی نصب موجود** آماده شده است. ابتدا [راهنمای PDF](INSTALL-UPDATE.fa.pdf) یا [راهنمای متنی](INSTALL-UPDATE.fa.md) را بخوانید و بکاپ هماهنگ شش دیتابیس و فایل‌های خصوصی هفت سرویس بگیرید.

- فایل اصلی دانلود: **babanoell-platform-2.17.0-update-kit.zip**
- ترتیب آپدیت: Identity، Documents، Integrations، Partners، Loans، Finance، Panel.
- هر ZIP فقط در آپدیتر سرویس خودش بارگذاری شود. نصب تازه یا bootstrap آپدیتر لازم نیست.
- [شرح تغییرات و موارد باز](CHANGELOG.fa.md)، [خلاصهٔ اعتبارسنجی](validation-summary.json) و [گزارش ارتقای آزمایشی و بازیابی بکاپ](deployment-rehearsal.json) همراه کیت هستند.
- صف پیامک وضعیت پرونده به‌طور پیش‌فرض غیرفعال است؛ تنظیم قالب و Cron در راهنما آمده است. پیامک واقعی یا انتقال پول در آزمون‌ها انجام نشده است.
- شواهد این نسخه: ۴۵ مجموعه تست، ۱۱ بررسی دیتابیس، ۶۹۳ بررسی HTTP و اعمال بسته‌ها با هر هفت آپدیتر. نسخهٔ نصب‌شدهٔ کاربر از این محیط کنترل یا تغییر داده نشده است.

این انتشار متن قراردادهای قبلی یا مبلغ سیکل‌های تاریخی بانک را بازنویسی نمی‌کند. ثبت‌نام و بازیابی حساب، پیامک وضعیت همکاری، متن نهایی قالب‌ها و پذیرش عملیاتی ارائه‌دهندگان همچنان در موارد باز گزارش ثبت شده‌اند؛ این کیت ادعای تکمیل تمام بخش‌های سامانه را ندارد.
