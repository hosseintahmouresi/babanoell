# انتشار Partners 1.4.0 — شاخص‌های قرارداد

- افزودن تعداد نسخه‌های قرارداد، نسخه‌های امضاشده و نسخه‌های در انتظار امضا به `/api/v1/stats`.
- تنها جدول مالک سرویس Partners (`contracts`) خوانده می‌شود.
- مجوز موجود `partners.merchants.read` برای خواندن آمار همچنان برقرار است.
- هیچ قرارداد، امضا، رکورد یا دیتابیسی تغییر نمی‌کند؛ Migration ندارد.
- اعداد به نسخه‌های قرارداد اشاره دارند، نه تعداد پرونده‌های یکتا.
