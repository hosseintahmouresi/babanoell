# Babanoell Documents 1.0.0

سرویس مستقل مدیریت مدارک پلتفرم بابانوئل — Phase 3.

## مسئولیت سرویس

- ذخیره‌سازی خصوصی فایل‌ها خارج از دسترسی مستقیم وب.
- پذیرش فقط JPEG / PNG / WEBP / PDF با بررسی MIME واقعی، پسوند، ساختار فایل، حجم و SHA-256.
- نسخه‌بندی غیرمخرب؛ جایگزینی فایل نسخه قبلی را حفظ می‌کند.
- اتصال عمومی مدرک به رکوردهای سامانه؛ در Phase 3 اتصال اصلی به `loan_request` است.
- بررسی مدارک با وضعیت‌های `pending` / `approved` / `rejected` و الزام دلیل برای رد.
- بایگانی منطقی بدون حذف سابقه.
- کنترل دسترسی مبتنی بر Permission و دسترسی رکوردی از طریق سرویس مالک رکورد.
- دانلود/پیش‌نمایش امن و Audit شده؛ لینک‌های کوتاه‌مدت یک‌بارمصرف فقط به‌صورت Hash ذخیره می‌شوند.
- `/health` و `/healthz`، Installer و Updater مستقل برای cPanel.

## معماری

Documents دیتابیس مستقل دارد و دیتابیس Identity یا Loans را مستقیم نمی‌خواند. احراز هویت و مالکیت پرونده از طریق HTTP JSON API نسخه‌دار بررسی می‌شود.

## ذخیره‌سازی

فایل‌های واقعی در `storage/private/` نگهداری می‌شوند. این مسیر در پکیج آپدیت محافظت‌شده است و فایل‌ها از طریق URL عمومی مستقیم ارائه نمی‌شوند.

## محدودیت پیش‌فرض

حد پیش‌فرض هر فایل 10MB است و Installer علاوه بر مقدار انتخابی، `upload_max_filesize` و `post_max_size` واقعی PHP هاست را کنترل می‌کند.

## نصب

1. دیتابیس مستقل Documents بسازید.
2. Document Root ساب‌دامین را روی `documents/public/` قرار دهید.
3. `https://documents.noeel.ir/install.php` را باز کنید.
4. محیط Staging، DB مستقل، URLهای Identity و Loans و سقف فایل را ثبت کنید.
5. پس از نصب، `/healthz` باید DB، private storage، Identity و Loans را `ok` گزارش کند.

جزئیات Release در `RELEASE-1.0.0.md` و معیارهای Phase 3 در `PHASE-3.md` ثبت شده‌اند.
