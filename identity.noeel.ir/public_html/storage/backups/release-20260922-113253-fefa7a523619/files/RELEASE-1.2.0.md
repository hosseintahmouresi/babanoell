# Identity 1.2.0 — unified UI release

تاریخ: 2026-08-26

## تغییرات

- بازطراحی کامل رابط مدیریتی Identity با هویت بصری پلتفرم بابانوئل.
- پالت رسمی: `#1D3559`، `#D0E2F2`، `#EDA900`.
- تایپوگرافی Yekan Bakh FaNum به‌صورت محلی و بدون وابستگی CDN.
- طراحی RTL و responsive برای موبایل، تبلت و دسکتاپ.
- استایل یکپارچه برای کارت، فرم، جدول، وضعیت‌ها، هشدارها و CTA.
- صفحه ورود updater، داشبورد updater، خطاها و وضعیت‌ها بازطراحی شدند.
- صفحه installer برای نصب‌های تازه با همین سیستم طراحی هماهنگ شد.
- جریان updater تکمیل شد: بعد از Validate، خلاصهٔ بسته + تأیید بکاپ + دکمه Apply نمایش داده می‌شود.
- قبل از Apply، SHA-256 همان بستهٔ Validate‌شده دوباره کنترل می‌شود تا فایل میان دو مرحله عوض نشده باشد.
- هیچ تغییری در `config/local.env.php`، `storage/` یا فلگ‌های احراز هویت اعمال نمی‌شود.
- هیچ migration جدیدی در این نسخه وجود ندارد.
