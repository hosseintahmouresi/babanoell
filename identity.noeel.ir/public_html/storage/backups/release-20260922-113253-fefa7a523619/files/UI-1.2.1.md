# Babanoell Identity UI 1.2.1

این نسخه هویت بصری سرویس Identity را با پالت رسمی پلتفرم یکپارچه می‌کند.

- Primary: `#1D3559`
- Secondary: `#D0E2F2`
- CTA/Accent: `#EDA900`
- Typography: Yekan Bakh FaNum (embedded in the bundled CSS so the updater does not need to accept font-file extensions)
- Framework-free, RTL, responsive, accessible focus states, no external CDN dependency.
- Shared assets: `public/assets/babanoell-ui.css`, `public/assets/babanoell-ui.js`, `public/assets/brand-mark.svg`.
- `public/install.php` is included for fresh installs; the updater intentionally protects the live installer and will not overwrite it.
