ابزار نمایش نسخه اصلاحی سه قرارداد بابانوئل — نسخه 1.0.0

شناسه‌های محدود: 1348، 1350، 1352 — فقط طرح شماره 34.

آموزش:
1) قبل از استفاده از دیتابیس و افزونه‌ها بکاپ مستقل بگیرید.
2) ZIP افزونه را از «افزونه‌ها > افزودن > بارگذاری افزونه» نصب و فعال کنید.
3) «ابزارها > اصلاح سه قرارداد» را باز کنید.
4) HTML کامل قراردادی را که ارسال کرده‌اید در کادر HTML بچسبانید.
5) «ذخیره و بررسی» را بزنید. هر سه پرونده و متغیرهای حل‌نشده نمایش داده می‌شوند.
6) مقادیر درستِ متغیرهای حل‌نشده را برای همان پرونده در JSON اختصاصی درج کنید.
7) فقط وقتی همه متغیرها حل شده باشند «ذخیره و فعال‌سازی نسخه اصلاحی» کار می‌کند.
8) با «بازگرداندن نمایش قراردادهای اصلی»، نسخه‌های امضاشده قبلی دوباره نمایش داده می‌شوند.

جزئیات مهم:
- هیچ یک از رکوردهای mlr_lc_sig_1348 / mlr_lc_sig_1350 / mlr_lc_sig_1352 در دیتابیس دستکاری نمی‌شود.
- هیچ اثرانگشت، تاریخ امضا، OTP و توکن قدیمی بازنویسی نمی‌شود.
- یک نسخه جدید و فاقد امضا صرفاً در لایه نمایش (فیلتر استاندارد get_option وردپرس) جایگزین HTML نشان‌داده‌شده می‌شود.
- روی نسخه اصلاحی، اطلاعیه آشکارِ نیازمند امضای مجدد قرار دارد.
- اگر کد اصلی افزونه به‌جای get_option از دسترسی مستقیم SQL برای خواندن نسخه ذخیره‌شده استفاده کند، این روش به‌تنهایی صفحه قرارداد اصلی را تغییر نمی‌دهد و بررسی PHP افزونه اصلی لازم است.
- چنانچه اعتبارسنجی با contract_digest روی HTML نمایش‌داده‌شده انجام شود، سازگاری نمایش باید با کد اصلی ارزیابی شود. این افزونه اعتبار امضای قبلی را به نسخه اصلاحی نسبت نمی‌دهد.
- این افزونه سند حقوقی امضاشده جدید صادر نمی‌کند. برای امضای نسخه جدید باید مجدداً فرایند پذیرش و OTP اجرا شود.

پیکربندی‌های افزونه در wp_options با پیشوند bcr_three_20261011_ ذخیره می‌شوند.

پیش‌نیاز PHP >= 7.4 و WordPress با جدول‌های bnd_loan_requests و bnd_options.
