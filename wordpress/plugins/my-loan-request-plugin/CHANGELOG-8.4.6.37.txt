My Loan Request 8.4.6.37 — Resilient Guarantor Upload Fix
============================================================

هدف این نسخه
------------
رفع خطای قطع اتصال/HTTP2 هنگام ذخیره اطلاعات و مدارک ضامن، بدون تغییر در دیتای موجود،
فرمول‌های مالی، تسویه، طرح‌ها یا گردش‌کار پرونده.

اصلاحات اصلی
------------
- فرم ضامن اول و دوم دیگر همه فایل‌ها را داخل یک درخواست multipart بزرگ ارسال نمی‌کند.
- هر فایل ضامن به‌صورت مستقل از طریق سرویس مرکزی آپلود می‌شود.
- فایل‌های بزرگ به قطعات 1MB شکسته و پس از تکمیل روی سرور مونتاژ می‌شوند.
- هر فایل به user + request_id + guarantor index + field key با HMAC token متصل می‌شود.
- درخواست نهایی ذخیره ضامن فقط متن + URL/token فایل‌های تأییدشده را ارسال می‌کند.
- URL خارجی یا token متعلق به پرونده/کاربر/فیلد دیگر پذیرفته نمی‌شود.
- آپلودهای نیمه‌کاره یا بدون ذخیره نهایی cleanup امن دارند.
- cleanup قبل از حذف، وجود reference در guarantor_info/guarantor_info_2 را بررسی می‌کند.
- در خطای دیتابیس، فایل‌های تازه‌ای که در همان تلاش ایجاد شده‌اند پاک می‌شوند.
- مسیر multipart قدیمی سمت PHP برای صفحات باز/cache‌شده قبل از آپدیت حفظ شده است.
- پنل پذیرنده، متقاضی، مدیریت، کارشناس بانک و مسیرهای مشترک جزئیات از uploader واحد استفاده می‌کنند.
- context سایت در WordPress Multisite از فرم تا آپلود و ذخیره نهایی حفظ می‌شود.
- هیچ migration یا تغییر schema دیتابیس در این نسخه وجود ندارد.

سازگاری
-------
- اطلاعات ضامن‌های قبلی بدون تغییر باقی می‌ماند.
- فایل‌های قبلی دوباره آپلود یا بازنویسی نمی‌شوند.
- فرمول‌ها و rounding مالی تغییر نکرده‌اند.
- منطق Secret Editor و Credentialهای ICS24 طبق محدودیت پروژه دست نخورده‌اند.
